#  Iris Dataset Chart Story

## Objective
Analyze the Iris dataset and present the findings through data visualization and storytelling.

## Charts
- Average Petal Length by Species
- Average Sepal Length by Species
- Dataset Composition by Species
- Average Petal Width by Species

## Key Insights
Iris-setosa has the smallest petals, Iris-versicolor has medium-sized petals, and Iris-virginica has the largest. Sepal length increases more gradually across the species. Each species contains 50 samples, providing a balanced comparison.

## Tools Used
- Microsoft Excel for the web
- Iris dataset
- Data visualization and storytelling

## Deliverables
- Excel workbook containing the charts and dashboard
- PDF export of the final dashboard
